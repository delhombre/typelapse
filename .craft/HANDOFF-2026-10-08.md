## Operating notes that saved time

- Every builder in its own worktree, its own `E2E_OUT_DIR` and port (5391 is
  usually taken by someone's preview server). Builders restart dev servers after
  edits before probing (HMR dual-instance poison).
- Wall-clock assertions stay out of CI (`@perf` tag, `grepInvert` unless
  `E2E_PERF`). Tag one case `@smoke` so a PR guards the regression.
- The SubagentStop hook's `pnpm lint` once ran in the main checkout and failed
  on `.craft/evidence/` JSON; `.craft/evidence/**` is now ignored by git and
  Biome (#224).
- `gh pr merge` can 502 while the merge lands: check `state` before retrying.
  An "Advisories: cancel" check comes from the concurrency group when runs
  queue; `gh run rerun <id> --failed` fixes it.
- Merge-on-green loops: wait for `Quality gate` to exist and every check to be
  non-pending, then `mergeStateStatus == CLEAN`, then merge; close the ticket
  with the commit and move the Project 4 card to Fait (option `515a978c`).
- The auto-mode classifier blocks `git worktree remove` and `git push --delete`
  for the agent: hand Bruno the command.
- For a visual decision, a one-page artifact with the real export frames and
  live controls got Bruno's answer in one message (caption plate,
  https://claude.ai/artifact/919L8BKED5YBs1Eqn5vWNk). Reuse the pattern.
- Reviewers caught, after green gates: a still without layers, a composition
  bridge inventing a title card, server ticks vs picture, a height-bounded fit
  bug, a boot guard that could evict a real project. Review every PR; re-review
  after a rework on a shared read path.
